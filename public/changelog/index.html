Release notes

Nexus 0.2.2 and planned work.

0.2.2

Windows x64

Downloads

Interface update

  • App layout. Kept the glass surfaces, reduced promotional copy and decoration, and added a practical overview with module counts and common actions.
  • Controls. Selected-page navigation, consistent dark dropdowns and clearer spacing.
  • Website. Shorter pages, direct labels, custom scrollbars and current app screenshots. The browser illustration and repeated promotional sections were removed.
  • Existing behavior. CursorBlur still uses the original native executable. ScrollFlow and the other native engines are unchanged. Settings, profiles and shortcuts carry over.

Previous releases

0.2.1 replaced the CursorBlur port with the original executable, fixed the diamond alignment, connected signed updates, made module errors visible, and corrected settings being applied before the Apply action.

0.2.0 integrated Glide scrolling and the shared WPF overlay clock. The original frame-rate and platform limitations still apply.

0.2.1 on GitHub ↗︎0.2.0 on GitHub ↗︎

Current limits

Windows x64 only. The executable is not Authenticode-signed. Overlay frame targets are not guarantees; CursorBlur has independent native timing. ClipVault history is memory-only. Third-party blur, cloud/live sync, arbitrary native plugin loading and embedded device controls are not included.

Broad mixed-DPI, HDR, elevation, application, performance and accessibility testing remains ongoing. Feature uninstall is logical; shared binary code remains in the app.

Planned work

  • Broader display and application validation.
  • More complete accessibility and high-contrast support.
  • Production publisher signing, rollback and update infrastructure.
  • An isolated plugin broker before loading untrusted extensions.

These are plans, without committed release dates.
