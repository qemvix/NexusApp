13 NOV 20260.2.0WINDOWS PREVIEWGet this release

A stronger foundation for flow.

  • ScrollFlow, powered by Glide. The native engine replaces the first Nexus scroll loop, adding finite eased pulses, native touchpad output where available, horizontal/vertical wheel fallback, exclusions and fullscreen policy.
  • CursorBlur joins the toolkit. A separate utility draws a trail from the actual system cursor image, with interpolation, fade, alpha and tint.
  • A shared frame clock. Composition-synchronized overlays replace the old low-rate timers. Choose a 60–240 FPS target and inspect measured drawing rates. Cursor Lens reuses its capture buffers.
  • One coherent platform. Shared hotkeys, profiles, explicit capabilities, local configuration and a unified per-user installer.
  • A supplied proprietary license. Official releases are permitted for personal desktop use under the published terms.

Validation, without inflated promises.

The release was built with warnings treated as errors. Local checks cover core configuration and lifecycle behavior, native cursor-image capture, a frame-clock probe and all thirteen module start/stop paths. The full interactive Glide wheel suite also passed after standalone Glide was closed and the mouse left still.

Clock probes on the reported 144 Hz desktop observed approximately 58–61 drawing callbacks per second at target 60, and roughly 72–81 at target 144 under those runs. These are test observations, not guaranteed presentation rates for every effect combination.

Topmost acceptance remains a manual check on some systems. A normal opacity/style restoration check passed; broad application, hardware and accessibility testing is still pending.

Known preview limits.

Feature install/uninstall is logical within one shared binary. External plugin distribution, live/cloud settings sync, persistent clipboard pins, now-playing titles, arbitrary third-party blur, full embedded device controls and unattended update installation are not included. The update feed and Authenticode signing are not configured.

Where the work goes next.

RELIABILITY

More real desktops.

Wider app and hardware testing, mixed-DPI refinements, accessibility auditing and measured CPU/GPU budgets.

CONTROL

Richer native tools.

A visual window-layout editor, app exclusions for focus tools, improved audio/device controls and more persistent workspace choices.

DISTRIBUTION

A stronger release pipeline.

Production signing, a publisher-operated update feed, rollback, and an isolated plugin broker before accepting untrusted native extensions.

Roadmap items are plans, not release-date commitments.
