Installation

Nexus is a Windows x64 application. Windows 11 is the primary tested platform; broader Windows 10 and mixed-DPI testing remains pending.

The installer creates a Start-menu shortcut and an Installed Apps entry for the current user. It requests no administrator elevation and adds no startup entry. For portable use, extract the ZIP and run Nexus.exe.

.NET is included. The original CursorBlur engine also needs Microsoft’s Visual C++ v14 x64 runtime; missing dependencies show a Runtime help action.

Unsigned Windows build

The executable has no Authenticode publisher signature. Review the release notes and compare the SHA-256 values. A matching hash confirms the file, not the publisher’s identity.

Permissions

Each module starts disabled. Open Permissions and review the mouse, keyboard, screen, clipboard, window-control or network capability it needs.

Blocked means an enabled module is missing a required grant. These are Nexus capability controls, not an operating-system sandbox for arbitrary native plugins. Revoking a required capability stops dependent features.

Protected video and secure desktop cannot be captured. Elevated applications can reject input or window changes from an unelevated app.

Privacy and capability details

Modules

Open the library to enable, disable or configure a utility. Changes in a settings editor take effect when you select Apply changes. Feature uninstall resets its configuration and releases active resources; shared code stays in the app.

Exit standalone Glide before enabling ScrollFlow. CursorBlur runs the bundled original executable and has no Configure screen. Its native timing and motion are independent of Nexus’s WPF rendering settings; disable it to stop its motion.

For Nexus-rendered overlays, select a 60–240 FPS target in Settings and inspect the measured rates. Monitor refresh, composition, capture cost and system load affect actual output.

Profiles and shortcuts

Assign module toggle shortcuts on Hotkeys. Nexus reports conflicts with shortcuts already owned by Windows or another app. Some feature actions use fixed shortcuts.

Profiles save module choices and settings. JSON exports exclude permission grants and clipboard contents. They can contain process names and weather coordinates, so review them before sharing. Profile transfer is manual.

Updates

Open Settings & updates and choose Check for updates. Available releases show a Download and install action. The updater verifies the signed manifest and installer hash, closes Nexus, updates the per-user installation and reopens it. Settings are kept.

Network permission is required. Daily checks are optional; installation remains your choice. Portable updates create or update the per-user installed copy. The signed manifest is separate from Windows Authenticode signing.

Troubleshooting

A module says Blocked

Review its required grants on Permissions. Enabling a module does not grant capture or system access automatically.

ScrollFlow will not start

Exit standalone Glide before enabling it. Its settings panel reports the selected output backend, routing status and output errors.

CursorBlur will not start

Close any standalone CursorBlur copy. Nexus reports duplicate engines, missing Visual C++ runtime DLLs and unexpected process exits on the module card.

An overlay looks slow

Compare the requested and measured rates in Settings. Reduce simultaneous effects or capture size under load. CursorBlur uses its own native timing.

Window opacity remained after a forced exit

Normal disable and exit restore supported window attributes. A crash can prevent restoration. Restart the affected application to restore its own window state.

Closing the window did not stop Nexus

Nexus remains in the notification area. Use Exit Nexus from its tray menu to release active hooks, overlays and timers.

Uninstall

Exit Nexus from its tray menu. Use Windows Settings → Apps → Installed apps → Nexus → Uninstall. Local settings are retained in %LOCALAPPDATA%\Nexus.

Installed files live in %LOCALAPPDATA%\Programs\Nexus. Portable and installed copies share the same per-user settings and cannot run together.
