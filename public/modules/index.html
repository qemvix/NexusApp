THE COMPLETE FEATURE GUIDE

Cursor & mouse≋

ScrollFlow

A little momentum goes a long way.

Bring touchpad-style movement to a regular wheel with the Glide scrolling engine.

  • Finite eased scrolling pulses
  • Native touchpad gestures where supported
  • Horizontal and vertical wheel fallback
  • Per-app speed, inversion and glide duration
  • App exclusions and fullscreen pausing

Capability

Mouse

Shortcut

Choose a toggle in Hotkeys

Current preview limits

Run ScrollFlow instead of standalone Glide. Native gestures require OS support; some applications coalesce fallback wheel packets.

Built on Glide
Cursor & mouse↗

CursorBlur

Give movement a softer edge.

The original CursorBlur executable, bundled with Nexus and managed with a single toggle.

  • Original native CursorBlur engine
  • No settings or Configure screen
  • Starts and stops with its module
  • Duplicate-engine protection
  • Stops even if the Nexus host crashes

Capability

Mouse

Shortcut

Choose a toggle in Hotkeys

Current preview limits

Uses its own defaults and timing; WPF FPS and reduced-motion controls do not change it. Disable it to stop motion. Requires the Microsoft Visual C++ v14 x64 runtime; missing dependencies show Runtime help.

Original CursorBlur

Cursor Aura

Keep your pointer in view.

Add glow, a soft halo, trails, particles or a spotlight around your pointer.

  • Five visual treatments
  • Adjustable radius and opacity
  • Custom accent color
  • Click-through desktop overlay

Capability

Mouse

Shortcut

Choose a toggle in Hotkeys

Current preview limits

The soft halo is a visual glow. For a trail of the actual cursor image, use CursorBlur. Click animation lives in ClickFX.

Cursor & mouse◌

ClickFX

Make every click visible.

Ripples, rings and shockwaves for presentations, recordings or a more tactile desktop.

  • Distinct left and right click colors
  • Ripple, ring and shockwave animations
  • Radius and duration controls
  • Optional Windows system sound

Capability

Mouse

Shortcut

Choose a toggle in Hotkeys

Current preview limits

Right-click color is fixed cyan in this preview. Custom audio files and independent animation timelines are not included.

Cursor Lens

Bring the small things closer.

A mouse-following magnifier for fine print, details and presentations.

  • Real screen magnification
  • Adjustable zoom and size
  • Circular or square framing
  • Optional presentation crosshair
  • Reusable capture buffers at the shared frame target

Capability

Screen

Shortcut

Choose a toggle in Hotkeys

Current preview limits

Protected video and secure desktop cannot be captured. HDR and mixed-DPI configurations need broader validation.

Your desktop▦

Float

Useful details. A small footprint on screen.

Keep a live clock, CPU, memory and media controls in a compact floating widget.

  • CPU, physical RAM and clock
  • Windows and processor information
  • Previous, play/pause and next keys
  • Optional coordinate-based weather
  • Always-on-top preference

Capability

Optional network for weather

Shortcut

Choose a toggle in Hotkeys

Current preview limits

Weather is fetched on enable. Now-playing titles, a widget designer and periodic weather refresh are not included.

Your desktop▥

WindowGlide

Put your windows where they belong.

Snap into useful layouts with shortcuts, eased movement and magnetic screen edges.

  • Half, quarter and third layouts
  • Custom normalized zones via JSON
  • Magnetic left and right edges
  • Eased window movement
  • Monitor work-area placement

Capability

Window control

Shortcut

Ctrl + Alt + arrow keys

Current preview limits

Targets normal captioned windows. Elevated or protected applications can reject changes; a visual layout designer is still planned.

Your desktop▤

ClipVault

Find the text you just copied.

Search, pin and reuse a bounded text and rich-text clipboard history.

  • Search up to 100 text/RTF entries
  • Pin and sort useful snippets
  • Copy rich or plain text
  • Delete an entry or clear the history
  • Memory-only storage

Capability

Clipboard

Shortcut

Ctrl + Alt + V

Current preview limits

History and pins are erased when the module stops or Nexus exits. No password-manager exclusion enforcement, image history or persistent vault is claimed.

Your desktop◧

FocusFade

Let your current window stand out.

Dim the desktop around the active window and give its edges a subtle highlight.

  • Click-through dimming
  • Adjustable dim amount
  • Accent outline controls
  • Nexus hub remains clear

Capability

Window control

Shortcut

Choose a toggle in Hotkeys

Current preview limits

This preview dims surroundings; it does not automatically hide windows or provide app exclusions and animated focus transitions.

Everyday tools⌗

ScreenRuler

A little more precision.

Measure pixels, read coordinates and pick screen colors without opening a full design tool.

  • Crosshair and ruler overlays
  • Anchored rectangle measurement
  • Physical-pixel coordinates
  • Copy a pixel color as a hex value

Capability

Screen

Shortcut

Ctrl + Alt + R / C

Current preview limits

Ruler labels are monitor-local. Capture colors are SDR values, and unusual scaling or rotated displays need testing.

Everyday tools⌘

KeyCast

Show the shortcut, keep the explanation simple.

An ephemeral keyboard and mouse overlay for tutorials and recordings.

  • Shortcut and all-keys modes
  • Mouse-button display
  • Color, size and duration controls
  • No keystroke log written to disk

Capability

Keyboard · Mouse

Shortcut

Choose a toggle in Hotkeys

Current preview limits

All-keys mode can expose passwords on screen. There is no automatic password-field detection; pause it before sensitive typing.

Everyday tools◇

Glassify

Let your workspace breathe.

Adjust opacity and topmost behavior for active or selected applications.

  • Window opacity control
  • Active-window or process-list targeting
  • Always-on-top preference
  • Original state restored on normal stop

Capability

Window control

Shortcut

Choose a toggle in Hotkeys

Current preview limits

Effects are best effort. No arbitrary third-party blur is included. Forced termination can prevent restoration; topmost behavior requires manual validation on some systems.

Everyday tools⊞

QuickDock

Your everyday controls, one shortcut away.

A floating dock for media, volume and the Windows controls you reach for most.

  • Volume and media keys
  • Windows sound mixer link
  • Display and brightness settings
  • Wi-Fi, Bluetooth, accessibility and power settings

Capability

No special module grant

Shortcut

Ctrl + Alt + Q

Current preview limits

Device buttons open native Windows settings. Nexus does not claim embedded Wi-Fi scans, Bluetooth switches or a universal hardware brightness slider.
