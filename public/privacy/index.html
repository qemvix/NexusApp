PRIVACY & PERMISSIONS

Your workspace.
Your say.

Useful utilities need access to useful things.
Here is what Nexus asks for, and what it does with it.

Local by default.

There is no Nexus account, advertising SDK, cloud-sync service or telemetry endpoint. Configuration and bounded error summaries stay in your local Nexus folder. Diagnostics do not collect input-event logs, clipboard contents, window titles or memory dumps; underlying errors can still mention a file path.

This website has no analytics or login system and does not set advertising cookies. Hosting and GitHub deliver files under their own service terms. Download links leave this site for the official GitHub release.

Capabilities, in plain language.

CapabilityUsed forWhat to know
MouseCursor effects, ScrollFlow and KeyCastPointer, click and wheel activity is handled in memory while enabled.
KeyboardKeyCastEphemeral display, no disk history. All-keys mode can expose sensitive typing on screen.
ScreenCursor Lens and ScreenRulerLocal pixel capture; color picking writes a hex value to the clipboard. Protected content is excluded.
ClipboardClipVaultAt most 100 text/RTF entries in memory, cleared on stop/exit. No persistent encrypted history.
Window controlWindowGlide, FocusFade and GlassifyWindow bounds, ownership and styles for native behavior. Some apps reject changes.
NetworkOptional weather and update checksWeather coordinates go to Open-Meteo; updates use the configured publisher host. The official signed GitHub-hosted feed is preconfigured; checks need Network permission.

A careful note about sensitive information.

Clipboard data may include secrets. ClipVault does not enforce every password-manager exclusion format in this preview; turn it off before sensitive copy operations. Pinning does not make an item persistent.

KeyCast’s all-keys mode can show passwords to people watching or recording the screen. It has no automatic password-field detection. Pause it before private typing. Shortcuts-only mode hides ordinary unmodified letters and digits, but other keys can still appear.

Permission controls are not a sandbox.

Nexus grants control trusted compiled modules inside the app. They are not an operating-system boundary for arbitrary native plugins. External plugin loading is not included in this preview. Revoking a capability stops dependent features; revoking network access cancels in-flight update operations.

Profiles and removal.

Profile exports contain module options, not clipboard history or grants. They can include app process names and weather coordinates, so review them before sharing. Settings are retained when you uninstall Nexus and can be removed manually after the app exits.
