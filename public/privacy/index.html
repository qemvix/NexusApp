Privacy and permissions

What each capability allows, and how Nexus handles local data.

Local data

Nexus has no account system, advertising SDK, cloud-sync service or telemetry endpoint. Settings and bounded error summaries stay in your local Nexus folder. Diagnostics exclude input-event logs, clipboard contents, window titles and memory dumps; underlying errors can still mention file paths.

This website includes no analytics, login or advertising cookies. Hosting providers and GitHub deliver pages and downloads under their own service terms.

Sensitive information

Clipboard data may contain secrets. ClipVault does not enforce every password-manager exclusion format; disable it before sensitive copy operations. Pinning an item does not make it persistent.

KeyCast has no automatic password-field detection. All-keys mode can show passwords to viewers or recordings. Pause it before private typing. Shortcuts-only mode hides ordinary unmodified letters and digits, but other keys can still appear.

Permission limits

Nexus grants control trusted compiled modules. They are not an operating-system boundary for arbitrary plugins. External plugin loading is not included. Revoking Network cancels in-flight update operations.

Protected capture, elevated applications and unusual display setups have operating-system limitations. Review the current limits for each module.

Profiles and removal

Exports contain module options, not clipboard history or permission grants. They can include process names and weather coordinates. Uninstalling retains local settings until you remove them separately.
